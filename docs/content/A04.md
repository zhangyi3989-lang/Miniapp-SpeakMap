# A04｜be/get used to + N / V-ing

> **已经习惯…… / 逐渐习惯……**
> 

用于表达自己对一种**环境、状态或行为的适应过程**。

[AI训练记录](AI%E8%AE%AD%E7%BB%83%E8%AE%B0%E5%BD%95%203f25008905f78166a99ae99f4143540e.md)

---

## 01｜理解这个母句

### 💡 一句话理解

当你想说：

> **“我已经习惯……”**
> 
> 
> **“我正在慢慢习惯……”**
> 

就可以想到：

> **be used to + N / V-ing**
> 
> 
> **get used to + N / V-ing**
> 

---

### 🧠 核心思维

> **be used to → 已经适应**
> 
> 
> **get used to → 从不适应到逐渐适应**
> 

> **I'm used to working from home now.**
> 
> 
> 我现在已经习惯居家办公了。
> 

---

### 🧩 通用结构

> **S + be used to + N / V-ing**
> 
> 
> **S + get used to + N / V-ing**
> 

这里的 **to 是介词**，所以后面接：

> **名词**
> 
> 
> 或
> 
> **V-ing**
> 

---

## 02｜变体

### 🔥 1｜高频用法

**① be used to + N**

已经习惯某种事物 / 环境。

> **I'm used to the weather here now.**
> 
> 
> 我现在已经习惯这里的天气了。
> 

**② be used to + V-ing**

已经习惯做某事。

> **I'm used to getting up early.**
> 
> 
> 我已经习惯早起了。
> 

**③ get used to + N / V-ing**

逐渐习惯……

> **I'm getting used to working from home.**
> 
> 
> 我正在逐渐习惯居家办公。
> 

**④ It takes time to get used to...**

适应……需要时间。

> **It takes time to get used to a new environment.**
> 
> 
> 适应新环境需要时间。
> 

### 👤 2｜主语变化

> **She's used to working under pressure.**
> 
> 
> 她已经习惯在压力下工作。
> 

> **Some people find it hard to get used to living alone.**
> 
> 
> 有些人觉得很难适应独居。
> 

核心不变：

> **主语变化 → be / get 跟着变化**
> 

---

### ⏱️ 3｜时态 / 时间变化

最值得掌握的是这三个阶段：

> **I'm not used to it yet.**
> 
> 
> 我还不习惯。
> 

↓

> **I'm getting used to it.**
> 
> 
> 我正在逐渐习惯。
> 

↓

> **I'm used to it now.**
> 
> 
> 我现在已经习惯了。
> 

这三个可以直接理解成：

> **不习惯 → 适应中 → 已经习惯**
> 

---

### ➕ 4｜否定 / 疑问变化

否定形式很常用：

> **I'm not used to speaking in front of large groups.**
> 
> 
> 我不习惯在很多人面前讲话。
> 

疑问形式理解即可：

> **Are you used to working under pressure?**
> 
> 
> 你习惯在压力下工作吗？
> 

---

## 03｜例子与区别

### 💬 代表例句

### Example 1｜学习

> **I'm getting used to speaking English without translating everything first.**
> 
> 
> 我正在逐渐习惯不先翻译、直接说英语。
> 

### Example 2｜工作

> **I'm used to working under pressure.**
> 
> 
> 我已经习惯在压力下工作。
> 

### Example 3｜健康

> **I'm getting used to exercising in the morning.**
> 
> 
> 我正在逐渐习惯早上锻炼。
> 

### Example 4｜生活

> **It took me a while to get used to living alone.**
> 
> 
> 我花了一段时间才习惯独居。
> 

### Example 5｜社会 / 抽象

> **People are becoming more used to using AI in their daily lives.**
> 
> 
> 人们正在越来越习惯在日常生活中使用 AI。
> 

---

### ⚖️ 关键区别｜used to vs be/get used to

这是这个母句最重要的区别。

> **I used to get up late.**
> 
> 
> 我以前经常晚起。
> 

强调：

> **以前这样，现在不同。**
> 

---

> **I'm used to getting up early.**
> 
> 
> 我已经习惯早起了。
> 

强调：

> **现在已经适应。**
> 

---

> **I'm getting used to getting up early.**
> 
> 
> 我正在逐渐习惯早起。
> 

强调：

> **现在处于适应过程。**
> 

记住：

> **used to + V → 以前常常**
> 
> 
> **be used to + N / V-ing → 已经习惯**
> 
> **get used to + N / V-ing → 逐渐习惯**
>

> 

---

### 🧪 2｜典型错误测试

#### 题目 1

“我已经习惯早起了。”

哪一句正确？

A. I'm used to get up early.

B. I'm used to getting up early.

#### ▶ 查看答案

**B**

> **be used to + V-ing**
> 

这里的 **to 是介词**。

---

#### 题目 2

“我以前经常早起。”

哪一句正确？

A. I used to get up early.

B. I'm used to getting up early.

#### ▶ 查看答案

**A**

> **used to + V = 以前常常**
> 

---

#### 题目 3

“我正在逐渐习惯新工作。”

哪一句更合适？

A. I'm used to my new job.

B. I'm getting used to my new job.

#### ▶ 查看答案

**B**

> **get used to → 强调适应过程**
> 
> 
> **be used to → 强调已经适应**
>
