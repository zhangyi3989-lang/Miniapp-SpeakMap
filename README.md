# SpeakMap

把学过的英语，真正调出来。

这是可以导入**微信开发者工具**的微信原生小程序，使用 WXML、WXSS、JavaScript 和 JSON。第一版只有文字输入，默认是明确标注的 Demo 示例模式；无需云环境、AI Key 或第三方 npm 依赖。

## 现在能做什么

- 首页自动安排任务：未完成任务 → 最早到期复习 → 可配置的快速调取 → 下一个未开始母句。
- 34个正式母句及详细学习资料（用户提供的 Notion 导出）；A01、E02、E03 保留已发布的训练任务，其余使用资料双语例句组装示例任务。每个包含 Phase 0、L1–L6（共 27 条回答，L1/L2 各六句整组提交，共 17 次提交）和 R1–R5 提示。
- L4 保持完整逻辑地图可见，当前节点高亮；表达帮助由用户主动展开。
- L5 两轮开放问题；L6 只有两个话题：Topic 1 先按观点/原因说约 30 秒，再保留原段并添加例子/影响扩展到约 60 秒；Topic 2 只显示题目，无逻辑链、表达帮助或历史回答提示。时间为练习目标，不进行录音时长校验。
- 保存真实回答、草稿、反馈和精确断点。退出后能继续同一道题、同一逻辑节点，包括已经提交但尚未点击“继续”的反馈。
- 自由表达、示例反馈、汇总候选、用户手动勾选入库。
- 表达库、错误库、自然升级库，支持搜索、按母句筛选、编辑、删除、去重。
- Retrieval First 复习：先写回忆、再看参考，记录自评和可选换场景造句。自评成功推进，失败次日重试。
- 真实本地统计、最近记录、JSON 备份恢复、两次确认清空。
- 与 SpeakMap 宣传册统一的暖杏色背景、白色便签页、装订孔与胶带装饰、黄色重点标记、深蓝文字、浅绿／淡蓝／淡粉分区和绿色主按钮。首页、学习库、复习、我的与训练流程统一样式，使用同风格本地小猫插画，没有远程图片。

Demo 不会分析用户输入，不评判是否答对或掌握。所有 Demo 候选都是参考来源；不会假装你的句子有错误或需要升级，所以当前默认只产生有参考价值的表达候选。错误库和自然升级库的数据模型、编辑、筛选、复习功能已经具备，未来由真实 AI 提供合格候选。三类候选都不能自动入库。

## 找到项目和导入

项目在 `/workspace/Miniapp-SpeakMap`。这次交付另外提供 `SpeakMap-demo.zip`，下载后先解压。也可以下载项目完整文件夹；不能只下载某一个页面。

1. 在电脑上安装并打开官方微信开发者工具，使用微信扫码登录。
2. 点击“导入项目”。
3. 选择包含 `project.config.json` 和 `app.json` 的 **Miniapp-SpeakMap 文件夹**，不要选 pages 文件夹。
4. 项目名称填 SpeakMap；项目类型选择小程序，不选择小游戏。
5. 没有真实 AppID 时，使用工具的“测试号”或“无 AppID / 游客模式”（选项名称取决于工具版本）。配置目前是 `touristappid`。这适合本地模拟器体验；预览到手机、上传发布可能需要自己的 AppID。
6. 第一版不需要选择或开通云开发，不需要构建 npm。
7. 点击“编译”，在首页点击“开始今天的学习”。

如果你的工具版本不接受游客配置，请在导入界面申请/选择工具提供的测试号。真实上线需要注册微信小程序获得自己的 AppID。

**有 AppID 后**，在 `project.config.json` 的 `appid` 字段替换 `touristappid`，或在开发者工具的项目详情里填写。AppID 不是 AI Key。

## 建议依次手动体验

1. 首次打开首页：统计应为 0，学习库为空。
2. 点击开始学习：进入 A01 的 Phase 0，再进入 L1，先自己写答案。
3. 提交：应显示“示例反馈”，同时保留你的原句。连续点击只保存一条。
4. 下一题后写一部分草稿，关闭页面、重新编译，再从首页继续：应恢复原题和草稿。
5. 在 L2 六句翻译草稿、L4“具体化”分别退出重进；已提交反馈也应恢复。
6. 完成 L1–L6，候选初始不勾选；勾选后入库，再次加入同一内容应提示重复。
7. 到学习库搜索、筛选、编辑和删除，返回后状态应同步。
8. 到“我的”查看原始回答，复制备份到笔记，再用备份恢复；恢复须先确认覆盖。
9. R1 默认完成训练后 1 天到期。到期后应先输入、再显示参考；自评和换场景回答保存后，下一次日期更新。
10. 关闭再启动小程序，记录仍应保留；清空需要两次确认。

想立即测试复习而不用等一天：仅在独立测试数据中，到 `config/trainingConfig.js` 将 `review.intervalsDays[0]` 临时改成 `0`，清空测试数据后重新完成一轮训练或入库。测试结束改回 `1`；该设置不会改变已经安排好的复习日期。不要改电脑时间，也不要修改真实学习备份。

## 数据和复习规则

数据仅在当前设备/当前开发者工具环境，存储键为 `speakmap_learning_v1`，通过 `services/storage.js` 统一读写。没有自动跨设备同步。清缓存、卸载或更换设备可能丢失记录。

进程由状态推进，跨天不会重置。复习间隔集中在 `config/trainingConfig.js`：R1–R5 默认为 1、3、7、14、30 天，每个间隔从上次完成时起算。失败保持当前阶段，1 天后再次复习。R5 自评成功只记录“完成复习周期”，不意味着系统认定掌握。

备份包含 `formatVersion`、`exportedAt` 和完整 `data`。在“我的 → 数据备份 / 恢复 / 清空”复制 JSON，粘贴到信任的笔记工具保存。恢复前校验版本、必要结构、记录关联和断点范围；必须确认覆盖。清空须两次确认。

保存失败时当前页保留输入，提示重试。读取损坏或未来版本时保留原存储并阻止覆盖；可恢复有效备份，或在确认后清空。所有用户回答标为 `provenance: user`；第一版没有真实正确性判断，所以不把它们自动计为成功的 `userProduced`。参考内容标为 `demo_reference`，未来 AI 生成内容标为 `ai`，均不能算自主调用。

## Demo 与未来真实 AI

`config/appConfig.js` 默认 `AI_MODE: 'demo'`。页面只调用 `services/ai/index.js`，不会直接依赖 Demo 实现。Demo 使用 Promise，原始输入正常保存，但反馈是题目相关的固定参考，不是真实分析。

未来接口位于 `services/ai/realService.js`，预留微信云函数 `aiProxy`。它目前是**调用接口预留，尚未部署真实后端**；不能只切到 real 就获得真实反馈。

未来接入顺序：

1. 在微信开发者工具中开通自己的云开发环境。
2. 在 `cloudfunctions/aiProxy` 实现服务端请求、身份校验、限额与返回结构；见目录内说明。
3. API Key 放在**云函数环境变量或安全后端环境变量**，不要放到小程序 JS、配置、Git、聊天或备份。
4. 服务端使用 `config/aiPrompt.js` 中的原则，返回与 Demo 相同结构，并检查输出格式。
5. 部署云函数后，在 `config/appConfig.js` 填 `cloudEnv` 和函数名称，再将 `AI_MODE` 改成 `real`。
6. 重启并验证失败重试、原句正确时明确肯定、仅对真实错误纠错、保留原意、候选来源和手动入库。

前端文件会打包到用户设备。把 Key 写进去会泄露，因此前端只通过安全代理调用。

## 宣传册视觉更新

页面采用宣传册的便签与卡片风格，而非整张海报嵌入页面。小猫 PNG 是根据宣传册角色制作的同风格透明插画，位于 `assets/speakmap-cat.png`，由 `brand-mascot` 组件显示。共有品牌页头由 `brand-header` 组件显示；二者按需在各页面 JSON 的 `usingComponents` 注册，组件自身不声明品牌组件依赖，避免递归注册。底部导航使用本地 PNG 图标。

更新已有项目时，复制新版 `assets`、`components`、`pages` 文件夹，以及 `app.json`、`app.wxss`，覆盖旧项目的对应文件。保留你自己设置的 `project.config.json` 和 `project.private.config.json`；无需清空学习存储。按 Ctrl+B 重新编译，依次检查四个底部页面、训练输入和窄屏布局。

出现模块未定义时：先确认原项目的 services/ai/index.js、demoService.js、realService.js 都存在。为排除多次局部覆盖和旧编译缓存，建议下载最新完整 ZIP 并解压到新文件夹，再导入该文件夹进行验证；保留旧项目，勿删除学习存储。日志中的渲染递归溢出已通过取消全局品牌组件声明、改为页面级按需声明来排除一个潜在原因，真实开发者工具中的结果仍需重新编译确认。

### 教学与训练导航

母句详情保留核心含义、场景和双语例句；“母句详细学习”进入独立页面，提供槽位拆解、逐步构句、易错对比和理解自测。详细学习页面展示用户提供的正式资料。L1 根据个人生活连续造六句；L2 显示六条中文，均每行一句、一次提交。旧任务只合并尚未回答的题目，保留原回答和草稿。训练页“← 上一步”回看原任务及已保存反馈；再继续可恢复当前草稿，回看不重复统计。左上角原生返回仍退出训练页。

首页“接下来的学习安排”只读展示断点及剩余阶段、按到期时间排序的具体复习轮次、回忆检查和下一新母句；未到期复习单独展示，随进度自动刷新。原“今日到期复习”卡片已合并。

学习记录与累计统计统一保留在“我的”，首页不再重复展示。

首页内容入口为“34个母句”和“12个功能表达”。功能表达展示已有12类用途和表达示例；母句全集及34份详细讲解已导入。

复习页默认展示错误库、地道升级库、Chunk库三个专项入口及到期数量，选择分类后仅显示对应条目；首页调度的母句复习仍使用原回忆、自评流程。
